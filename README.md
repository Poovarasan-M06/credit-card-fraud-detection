**💳 Credit Card Fraud Detection & Analysis (Power BI)**
**📌 Project Overview**

This project focuses on analyzing credit card transaction data to detect fraud patterns using Power BI Desktop.
The dashboard provides clear insights into fraud distribution, transaction behavior, merchant categories, velocity patterns, and location mismatches.

The goal of this project is to:

Identify fraudulent transactions

Understand fraud patterns

Visualize risk indicators

Support decision-making through interactive dashboards

**🎯 Key Insights**

Fraud percentage is very low compared to total transactions.

Certain merchant categories show higher fraud concentration.

Velocity (transactions within 24 hours) is a strong fraud indicator.

Location mismatch increases fraud probability.

Late-night transactions show higher transaction volume.
